# 1. Project Title and Description

EG Academic Management System is a web based academic management system developed to help lecturers and students manage their academic activity in one platform.

The system provides two different user portals which is Lecturer Portal and Student Portal. Each portal has its own dashboard and features to support academic management, student monitoring and learning activity.

The system is designed with a simple, user friendly and responsive interface using a soft pink and lavender colour theme. It also includes a light and dark mode feature to improve the user experience.


# 2. Features Included

EG Academic Management System includes the following features:

# i. Login and Account Management
- Login system for Lecturer and Student accounts.
- User account type selection.
- Student registration.
- Forgot password and password reset interface.
- Demo login credentials provided on the login page.
- Show and hide password functionality.
- Logout confirmation.

# ii. Lecturer Portal
- **Dashboard:** Displays an overview of academic information and statistics.
- **Student Management:** View and manage student information.
- **Course Management:** Manage available courses.
- **Attendance Management:** View and manage student attendance.
- **Assignment Management:** Manage student assignments and submissions.
- **Reports:** Display academic reports and performance information.
- **Profile Management:** View and update profile information and profile picture.

# iii. Student Portal
- **Dashboard:** Displays an overview of the student's academic activities.
- **My Courses:** View enrolled courses and course information.
- **Calendar:** Mark assignment due date and important events dates.
- **Assignments:** View assignments, deadlines and submission information.
- **My Performance:** Monitor academic progress and performance.
- **Notifications:** View notifications and mark them as read.
- **Profile Management:** View and update personal profile information and profile picture.
- **Settings:** Manage student account preferences.

# iv. Additional Features
- Light mode and dark mode.
- Responsive website layout.
- Sidebar navigation.
- Search functionality.
- Interactive buttons and forms.
- User friendly interface.
- Consistent design across both portals.

# 4. Frameworks and Libraries Used

 Framework/Library | Purpose

# 5. Conclusion
